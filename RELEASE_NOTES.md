## Sky Gauge Card v0.1.0 · by Kopterworx

First regular release — no beta or pre-release flag.

A responsive Home Assistant gauge card that starts at **3 × 2** and grows with your dashboard. Configure it quickly in Simple, or select parts of the live gauge in Advanced and customize the details.

**Highlights**
- Single/Dual, independent ring colors and optional secondary units.
- Full color / Progress / Indicator only.
- Ranges / Fixed / continuous Gradient, with real-value boundaries.
- Visual typography, geometry, indicator, icon and card styling.
- Browser-local presets, Style only / Full configuration and resets.
- Native entity and icon search.
- MIT licensed; all features free.

**HACS:** add `https://github.com/krleas/sky-gauge-card` as a **Dashboard** custom repository, download and refresh the browser.
