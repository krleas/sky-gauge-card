# Changelog

## v0.1.5 — 2026-11-12

- Move the gauge rings, indicators, and readings up or down with **Vertical position** in **Advanced → Arc geometry**.
- Choose bundled **Barlow Semi Condensed** or **IBM Plex Mono** in **Advanced → Main value**. Both fonts load locally.
- Rename the generic sans-serif option to **Browser default**. Existing saved configurations remain compatible.

## v0.1.1 — 2026-11-02

- Fix the sponsorship banner in HACS by using linked Markdown instead of an HTML image.
- Use absolute image URLs in README for reliable rendering outside GitHub.
- Gauge behavior is unchanged.

## v0.1.0 — 2026-11-02

First regular release of Sky Gauge Card by Kopterworx.

- Responsive Single and Dual gauges, minimum 3 × 2, default 4 × 3.
- Simple setup and visual Advanced editor with live preview.
- Full color, Progress and Indicator only arc styles.
- Ranges, Fixed and continuous Gradient color modes, independently configurable per Dual ring.
- Source-value color boundaries, add/remove color ranges and gradient points.
- Line and dot indicators with size, color and outline settings.
- Value, unit, icon, name, arc and card appearance controls.
- Adjustable Soft shadows and Glow.
- Browser-local presets with Style only / Full configuration, section reset and appearance reset.
- Native Home Assistant entity and icon selectors.
- Missing-data and long-name handling.
